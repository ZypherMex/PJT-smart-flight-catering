If a phone can't open it

  1. Check the phone is on the same Wi-Fi as this computer (not mobile data, not a guest network that blocks devices).
  2. Try typing the address above into the phone's browser instead of scanning.
  3. On Windows, the first run may ask to allow the server through the firewall. Choose Allow for private networks.
  4. Still stuck? Set PUBLIC_URL in the .env file to the correct address and restart the server.
